01 · The Ask

Six pillars, one brand

A site for Paty Straffon organized around The M Program (flagship), Thrive (standalone class), Retreats & Events, Shop, Blog, and About Me — styled in the spirit of Melissa Wood Health, The Sculpt Society, and The Class, with Thrive specifically echoing The Class's calmer vibe.

02 · Research

What each reference site does well

Melissa Wood Health

Membership-first funnel; warm cream palette; serif-italic headline over full-bleed editorial photography.

The Sculpt Society

Method → class types → social proof → pricing → shop, in that order. Membership is the hard sell throughout.

The Class

Tiers digital vs. in-person; philosophy before pricing; minimalist type, muted natural-light photography. Model for Thrive.

06 · A Build Note

The original plan was Claude Design's multi-artboard canvas tool, but this machine has no Node or Bun installed, which that tool requires. Pivoted to a single self-contained HTML page instead — with the side benefit that the nav bar performs real click-through navigation between all 7 pages, rather than panning around a canvas.

10 · The Platform Plan

How this actually gets built & run

The domain (www.patystraffon.com) is already owned at GoDaddy. Here's the stack decided on, and why.

Hosting: Squarespace, not Shopify or v0/Vercel

The deciding factor: this is a solo operation adding blog posts, retreats, and a small markup-and-forward product catalog — content-heavy, not commerce-heavy. Squarespace's native Events collection (built for exactly "list of retreats with individual pages"), native Blog, and Commerce tier (fine for a catalog this size with third-party fulfillment) cover all of it without code. v0/Vercel would mean rebuilding commerce from scratch and coming back to a developer for every content change; Shopify's extra commerce depth (multi-channel, complex inventory) isn't needed for a markup model.

Squarespace + Trainerize: different jobs, not redundant

Squarespace is the public front door (discovery, storytelling, selling). Trainerize is the private coaching delivery — workouts, nutrition tracking, progress, messaging — for enrolled clients only. They don't integrate with each other; the connection is a manual hand-off. Recommended model: sell The M Program as a Squarespace product, then manually invite the client into Trainerize — one payment system to reconcile, and the manual step matches the brand's "conversations, not a funnel" framing at this cohort size. Thrive doesn't touch Trainerize at all — it's in-person, so Squarespace + Acuity handles the whole booking flow alone.
